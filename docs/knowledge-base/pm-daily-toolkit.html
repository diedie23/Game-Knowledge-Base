📋 一、每日站会记录 & 日报

15 分钟站会只回答三个问题；日报是站会的异步文字版。别写成周报，越轻越好。

🚧 二、Blocker（阻塞项）追踪表

Blocker 是 PM 的头号 KPI——每一条都要有"谁、几时前、解不解得了"。悬而未决的 Blocker 就是明天的延期。

#阻塞项阻塞谁负责推动需谁支持期望解除状态
1等程序提供背包接口UI组PM主程7/25🔴 阻塞中
2原画风格待制作人确认原画主美制作人7/24🟡 跟进中
3…🟢 已解除
📌 PM 每日动作：① 站会收集新 Blocker → ② 每条指定"推动人 + 期望解除时间" → ③ 超时未解的升级上报（找制作人/跨部门负责人），绝不让它默默过夜。

✅ 三、里程碑验收清单（Definition of Done）

卡里程碑最怕"差不多了吧"。DoD 是"到底算不算做完"的白纸黑字标准，评审前逐项过。

📝 四、变更请求（CR）登记台账

口头"稍微改改"最坑。所有变更进台账，让成本和责任可追溯。成本怎么算见决策中心的速算器。

CR#提出人/日期变更内容影响资产评估成本决策拍板人状态
CR-001策划/7-20主角配色调整2个立绘1.5人天✅批准制作人已完成
CR-002运营/7-22新增活动Banner3张切图2人天⏸延后PM待排期
CR-003…评估中
📌 落地流程：收到变更 → 登记台账（先不动工）→ 用 量化决策中心 的速算器估成本 → 按放行红线决定 PM 直批 / 走评审 / 冻结期不接 → 记录拍板人。无台账记录的变更，不动工。
